[R4]
Non, vous ne pouvez pas faire de donjon ensemble.

Sur WoW Forever, les règles de fonctionnement séparent complètement les types de serveurs/règles (rulesets). (source : Reddit)

Voici concrètement ce que cela implique :
- Isolation totale : Un personnage créé sur le mode Normal (PvE) et un personnage créé sur le mode PvP évoluent dans des mondes étanches. Vous ne pouvez pas vous grouper, vous voir, chatter ou lancer un donjon/raid ensemble. (source : Reddit)
- La seule exception (les champs de bataille) : Les files d'attente pour les Battlegrounds (Champs de bataille instanciés) peuvent parfois mélanger les joueurs de différents modes, mais cela ne s'applique pas aux donjons PvE. (source : Mythic Store)

Comment jouer ensemble ?

Pour pouvoir taguer et faire des donjons côte à côte, il faut impérativement que vous soyez sur le même mode de jeu.

Si vous voulez vraiment jouer avec ton pote, l'un de vous doit recruter un nouveau personnage sur le ruleset de l'autre (soit tu vas sur le PvP, soit il vient sur le Normal). Attention toutefois : sur le mode PvP, gardez en tête que les restrictions de factions (limitation à une seule faction par compte selon les règles du mode PvP) s'appliquent aussi. (source : Mythic Store)

Tu veux savoir quel mode (Normal ou PvP) est le plus adapté pour vous deux selon vos habitudes de jeu ?
